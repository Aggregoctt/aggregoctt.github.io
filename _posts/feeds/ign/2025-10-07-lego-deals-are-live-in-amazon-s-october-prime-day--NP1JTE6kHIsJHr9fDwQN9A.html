LEGO Creator 3-in-1 Forest Animals Red Fox

I love the 3-in-1 sets because they’re so reusable. While most LEGO sets let you build one thing, these let you build three sets, all using the same bricks. In this case, you can build three woodland animals: a fox, a squirrel, and an owl. Note that you have to take one animal apart to build the next, as they all use the same bricks.
