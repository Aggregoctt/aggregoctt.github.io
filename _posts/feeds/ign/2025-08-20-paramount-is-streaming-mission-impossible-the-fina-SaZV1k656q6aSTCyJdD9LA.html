Paramount is currently streaming Mission: Impossible – The Final Reckoning on its YouTube channel…in Morse Code.

Viewers flocked to the Paramount Movies YouTube channel today when it teased it would be streaming the latest Tom Cruise action movie in its entirety. Those who tune into the broadcast, unfortunately, will not be met with images of Ethan Hunt’s new globe-trotting journey. Instead, they’ll find a knife, a radio, and a lot of beeps and a lot of dashes.

“A secure livestream of Mission: Impossible – The Final Reckoning full movie is running now,” Paramount’s livestream description says. "But the Entity has infiltrated every major streaming platform, so this livestream was compromised. The full script had to be transmitted in Morse Code to avoid detection. We need your help decoding it.”

It’s a direct translation of the Mission: Impossible – The Final Reckoning script into morse code, meaning the stream will be very, very long if it wants to send through every emotionless beep from the film’s two-hour-and-50-minute runtime. Even if not all of the 700 people listening to the movie in Morse Code form can translate every last syllable, they seem to be having fun for now.

“I love this part!” one fan joked in the comment section.

“This has to have been Cruise’s idea,” another adds.

Mission: Impossible – The Final Reckoning’s Morse Code debut is certainly a creative way to celebrate its jump to digital. The eighth Cruise-led Mission: Impossible film finally became available to watch on platforms like Amazon’s Prime Video yesterday, giving audiences a chance to see the classic action series’ latest outing following its theatrical premiere in May. It’s still not available on Paramount+ quite yet, but at least you can listen to it until then, right?

Paramount’s Morse Code cabin is a reference to a similar cabin in the film, which is also located in a snowy area. Don’t count on Ethan Hunt and the rest of the Mission: Impossible team showing up any time soon, though, as it looks like this stream will be here for quite a while longer.
