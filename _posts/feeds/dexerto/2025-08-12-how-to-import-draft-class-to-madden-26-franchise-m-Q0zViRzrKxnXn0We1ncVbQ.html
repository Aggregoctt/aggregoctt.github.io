Madden 26 is here, which means starting up a Franchise mode and leading your favorite NFL team to glory. And, you can do so with custom draft classes too. 

The start of a new Madden cycle is always an exciting one for football fans. There is plenty to dive into with regard to Ultimate Team, Superstar Mode, and, of course, beating your friends online in Head-to-Head. 

For many, though, the first port of call if Franchise mode. If you’re a fan of a team that is struggling in real life, making them a dominant force on the virtual football field is a big achievement. 

You can always use the real-world roster to make things as realistic as possible, or you can you use custom draft classes to spice things up a bit. If the latter part of that interests you, well, you’re in luck.

How to add custom draft class in Madden 26


Using a custom draft class in Madden 26 is pretty simple. Like previous years, you can download a draft pool from the in-game Download Center. There will be any number of created classes to choose from, including current day players and retired stars too.

Once you’ve selected the draft pool you want, head over to Franchise mode. Make sure you’ve completed the pre-season and are into week one.

You will then have an action in the main Franchise menu for Choose Draft Class. Simply click on this, press Import Local File, and then select the draft class that you want to use. 

  1. Go to the ‘Home’ screen of Franchise mode
  2. Scroll to Choose Draft Class
  3. Select ‘Import Local File’ 
  4. Click on the draft class you want to use
  5. After a few seconds, the import will be complete!

After a few seconds, the draft class will have been added to your Franchise mode, and you’ll then be able to select these players at the next NFL draft.
