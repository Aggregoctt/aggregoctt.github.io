How to redeem codes

You can redeem codes in the game without any prerequisites by following these steps:

  • Tap the ‘Shop‘ option on the left side of the screen.
  • Swipe to the last tab under ‘Resources‘ in the new menu.
  • Tap the ‘ENTER CODE‘ option.
  • Enter an active code in the text box.
  • Tap ‘ENTER‘ to redeem the code.

Note – If you’re redeeming a code via QR, simply open the game and scan the QR code using your phone’s camera. Follow the link that appears to redeem the code.
