Destiny Rising is the very first mobile game to be set in the Destiny franchise, and it’s already filled with tons of weapons, chests, and loot. However, invite codes can be used to get some added bonuses for free.

Most Destiny games are a little grindy. After all, if you want to defeat the bosses and become the most powerful you can be, you have to grind through a little XP or complete a few quests to get the right tools or weapons.

Destiny Rising is no different, but as it’s a free mobile game, you can buy some of the items with real money. That is, unless you have some invite codes.

Active codes in Destiny Rising

As of August 29, 2025, there are no official codes for Destiny Rising following the expiration of ‘destinyrising828‘, which was limited to 1,000 redemptions.

However, there are invite codes, which can offer you a few rewards if you’re looking to dive into the game for the first time. We’ve uncovered a few for you to use, but only one can be redeemed per account, and you have to be on the same server.

If you do have friends playing Destiny Rising, we recommend asking them for their Invite Code before joining, as that way you’ll be able to add them as a friend too.

Bear the Light event

You can also bag a free code as part of the game’s Bear the Light event. Complete all the objectives, and you’ll be sent a unique redemption code to redeem on Bungie’s official site.

When you do, you’ll be given in-game rewards immediately.

How to redeem codes

Thankfully, redeeming codes in Destiny Rising is pretty simple, all you need to do is follow the steps below:

  • Log in to Destiny Rising.
  • Complete the Prologue.
  • Click on the cog on the bottom left of your screen.
  • Navigate to Other.
  • Click the Redeem button next to Exchange.
  • Paste in the code and press Exchange.

As mentioned above, the codes must be on the same server, so be sure to check what server you’re in and redeem the right code. They’re also case sensitive, so we recommend copying and pasting the code from the table above.

List of expired codes

Currently, there’s only one expired code in Destiny Rising, but when more are added and eventually expire, we’ll be moving them here, to save you from redeeming codes that don’t work.

What are Destiny Rising codes used for?

Currently, the Destiny Rising invite codes offer two rewards, Bon Voyage Charms and Lumia Leaf. Both are extremely useful items throughout the game.

Bon Voyage Charms are the currency you need for the game’s gacha pulls and Lumia Leaf is the premium currency you can use to gain more Bon Voyage Charms. So, if you want to pull on the gacha, you’ll need to redeem a few codes.
