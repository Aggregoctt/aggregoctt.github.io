Shadowverse: Worlds Beyond referral codes will give you free rupies, which can be used to unlock new card packs. So, here’s exactly how you can get your code and how many rupies you can receive for each referral. 

The popular anime card collecting game Shadowverse: Worlds Beyond has finally launched, giving TCG fans the chance to delve into its competitive multiplayer battles. However, if you wish to get an edge over your competitors, you’ll need to get your hands on the best cards. 

Fortunately, Shadowverse: Worlds Beyond’s friend referral event will reward you with thousands of rupies that you can use to unlock new packs. 

Shadowverse: Worlds Beyond referral code location

The Shadowverse: Worlds Beyond referral code location can be found by following these simple steps:

  1. Boot up Shadowerse: Worlds Beyond. 
  2. Click on the square icon in the top right of the screen. 
  3. Select the ‘Invite’ button.
  4. Click the ‘Enter Invite Code’, then paste the player’s code into the textbox. 
  5. Copy your invite code and give it to any players you wish to share it with. 

You can receive up to 20 Shadowverse: Worlds Beyond referral code rewards, so be sure to add new players to claim every available reward. 

Invite rewards

Anyone who uses your Shadowverse: Worlds Beyond code will get 2,000 rupies when they redeem your invite code, and you’ll earn up to 10,000 rupies in total as they progress through their Invite Missions.

  • Friend achieves D0 rank (up to 5): 400 rupies – 2000 total
  • Friend achieves C0 rank (up to 5): 400 rupies – 2000 total
  • Friend achieves A0 rank (up to 5): 600 rupies – 3000 total
  • Friend clears Dreizehn’s story (up to 5): 600 rupies – 3000 total

What are rupies used for?

Rupies are currently used to purchase card packs from the Legends Rise card banner. One pack will cost you 500 rupies, so you’ll need to farm a lot of this currency if you wish to purchase packs without spending any money. 

There you have it, that’s how you can use Shadowverse: Worlds Beyond codes to refer a friend and get plenty of free rupies.
