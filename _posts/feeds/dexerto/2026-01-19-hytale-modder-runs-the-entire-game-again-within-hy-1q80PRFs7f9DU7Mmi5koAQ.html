It turns out the sandbox game Hytale can even run its own game within itself, thanks to a talented modder’s effort.

It hasn’t even been a week since Hytale’s early access launch went live to soaring viewership, and the devs are already pushing updates to keep things fresh and exciting. And let’s not forget the modding community, too, which has been moving just as fast.

One user who goes by iamcxv711, a 15-year-old modder, has already surprised both players and the devs with some wild experiments, ranging from running Windows 95 to Doom inside the game.

Even crazier, though, is the fact that they’ve managed to play Hytale inside Hytale, or, as you might call it… Hytaleception.

Hytale modder runs Hytale inside its own game

Hytale inside Hytale is pretty much exactly how you’d picture it. In a video shared on X, the game can be seen running in a smaller pop-up window, while the main Hytale session continues in the background, all at the same time.

The ‘mini Hytale’ is a bit laggy, but from the looks of it, it’s still playable. The user can walk around, open their inventory, and even place blocks, just like in a normal playthrough.

Considering the game has only been out for five days, it’s impressive that a player has already pulled off something like this, so much so that the official Hytale account even replied in the comments with a nodding GIF.

When asked how they pulled this off, along with running Windows 95 inside the game, the modder explained that the process was actually less complex than the one behind Windows 95.

They added: “Windows 95 required reworking jPC to properly support headless mode, which meant hours of tinkering and messing with the BIOS. Here, it’s a custom VNC client connected to a PC running the game. It’s headless too.”

It was only a matter of time until something this unique caught a lot of attention. Many praised the user for pulling it off, while others couldn’t resist cracking a few jokes.

“We heard you like Hytale. So we put Hytale in your Hytale, so you can Hytale while you Hytale,” one person wrote.

Meanwhile, another jokingly added: “We got Hytale² before GTA6.”
