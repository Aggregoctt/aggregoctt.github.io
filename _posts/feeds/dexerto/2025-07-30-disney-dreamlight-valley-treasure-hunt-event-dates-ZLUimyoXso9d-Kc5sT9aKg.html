A brand new event is here in Disney Dreamlight Valley, bringing a little bit of pirating to the Valley through the Treasure Hunt event.

Disney Dreamlight Valley is no stranger to a good event, whether it’s a festive one that comes around every year, like Easter or the Holidays, or events themed around certain characters and items, like the Cheshire Cat Chaos or Memory Mania.

Well, a brand new one has finally arrived, this time it’s inspired by all things Peter Pan and Pirates. Players will need to dig up treasure, solve clues, and locate Memories, which will offer different rewards and a new picture. So, here’s all you need to know so you can make the most out of it.

The Treasure Hunt event will be active from July 30, 2025 to August 12, 2025.

As such, players will have just under two weeks to complete all the tasks and grab all the available rewards.

Where to find Treasure Cracks & Treasure Notes

The primary feature of the Treasure Hunt event has you looking for Treasure Cracks, which in turn offer you Treasure Notes. These become clues as to where you need to hunt for that buried treasure.

To find Treasure Cracks and therefore Treasure Notes, you need to look for a golden glowing spot in the ground, like the ones you can dig up at any time in the game. They can spawn in any open biome and will only appear once per day.

How to find event Memory Orbs

When you remove the correct obstacles shown in your clue, you’ll be given a golden chest with various rewards.

One of which will be a red Memory Fragment, which will help you complete the Dreamlight Duty and the final picture.

Duties & rewards

Duties

There’s only one Duty to complete in the Treasure Hunt Event: Expert Treasure Hunter.

To complete it, simply uncover 2 Event Memory Orbs during the event. We don’t yet know what the reward is for completing this task, but when we find enough Orbs, we’ll be sure to add it here, so check back soon.

Rewards

Lastly, you can bag some more rewards and a brand new picture by opening enough Memory Orbs. Uncover four Memory Orbs and you’ll unlock the new image.
