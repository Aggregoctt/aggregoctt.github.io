If you’ve started the Last Wish quest in Dying Light The Beast, you’re probably run into trouble finding Iris’ safes.

They’re nowhere to be found, and each is locked with a code that isn’t exactly written on the wall. Plus, opening the wrong one can stall your progress.

I’ve played through the steps myself, so here’s a clear walkthrough of every Iris safe code and how to get through this quest without wasting time spinning dials.

How to complete all Last Wish

To complete Last Wish, you’ll need to find Iris’ safe and open it using the correct safe code. Still, there are two more safes you can crack open:

  • The code for Iris’ main safe is 20-07-06. Use the safe on the left of the two on the table. This is the one with the music box.
  • Extra Iris safe on the desk is opened with the safe code 11-17-08. Valuables
  • The code to open the third Iris safe opposite this desk is 71–61-45. Valuables.

Let’s go over each part step-by-step:

Find Iris’ notebook clue for the Last Wish safe code

Once you accept Last Wish, head to Iris’ shop and home. Before you start spinning dials, check the notes littered around the interior. The key one is a small birthday reminder that reads like a date for a grandchild.

That is the hint for the main combination. The birthday translates to 20-07-06, and it’s specifically for the music-box safe you actually need for the quest. Use your Survivor Sense to sweep desks and counters so you do not miss the slip.

How to find the Iris safe after it disappears

Once you’ve got the clue, the safe vanishes from its shelf.

The objective pushes you to keep searching. Use Survivor Sense and check the floor near the broken entry points and windows.

You will pick up muddy footprints that lead you out and around. Follow them through the nearby warehouse, though the entrance is through a window high up the left-side wall.

Main Iris safe code

In the living area you’ll see two strongboxes side by side on top of a desk. Go for the left safe and enter 20-07-06. That is the quest-critical one containing Iris’ Music Box.

If you open the right box first by mistake, no harm done, but you will not progress the main quest’s step.

Other safe codes

Two more Iris-related safes show up in this chain.

  • One is on top of this very same desk, but to the right. Punch in 11-17-08.
  • The last Iris-tagged lock is right across it, on top of another desk with some rope and a toolbox. Use 71-61-45 here.

Again, the reward is valuables, so do not expect a unique quest item here.

That is everything you need for Last Wish, with all three Iris-linked safes covered and the clean codes to punch in.
