Microsoft ha distribuito una nuova build di anteprima per Windows 11, la 26100.4767 (KB5062663), agli iscritti al canale Release Preview. Questo aggiornamento, che segue a breve distanza la release precedente, si concentra sulla correzione di una serie di bug che affliggevano diversi componenti del sistema operativo, dalla gestione grafica al Firewall, fino a Windows Copilot.

Tra le risoluzioni più importanti vi è quella legata a un problema che poteva causare il crash del Task Manager durante l'interazione con l'intelligenza artificiale di Copilot, ed è stato inoltre risolto il bug che generava un falso evento di errore ("Config Read Failed") nel log di Windows Firewall, un'anomalia che, sebbene innocua, poteva destare preoccupazione negli amministratori di sistema.

L'aggiornamento interviene anche su problemi legati alla grafica, in particolare correggendo un bug che poteva far apparire una schermata verde inaspettata su alcuni display. Sul fronte di Windows Copilot, è stato risolto un problema che impediva la corretta visualizzazione delle icone delle app all'interno della barra delle applicazioni di Copilot in Windows.

La build 26100.4767 è in fase di rollout per gli iscritti al canale Release Preview di Windows 11 e anticipa le correzioni che verranno incluse nei prossimi aggiornamenti cumulativi destinati a tutti gli utenti. Attendiamo quindi che la build raggiunga in futuro anche gli altri rami, sino al suo rilascio pubblico.
