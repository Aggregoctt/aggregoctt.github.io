Microsoft sta lavorando a un’app dedicata per OneDrive su Windows 11: lo sostengono i colleghi di Windows Central, che sono riusciti a condividere qualche screenshot preliminare. A quanto pare l’app è stata scovata sui server di Microsoft, per quanto si tratti di una build sperimentale, ed è basata su tecnologie web - potrebbe trattarsi insomma di un altro “wrapper”, sostanzialmente un browser custom che carica e visualizza un sito internet, come accade per la nuova versione del client di posta elettronica Outlook.

Quando l’app viene lanciata, l’icona compare nella taskbar come per qualsiasi altro applicativo; è incentrata soprattutto sulla multimedialità - la pagina iniziale mostra infatti la propria libreria di foto e video. L’interfaccia è un mix del Fluent Design tipico delle iterazioni più recenti di Windows e delle interfacce web del colosso di Redmond: la grafica è prevalentemente scura, ci sono molti pulsanti a forma di “pillola” (un rettangolo con due semicerchi ai lati, per capirci) e si osserva in varie parti l’effetto di sfocatura “Acrylic” tipico di Windows 11.

Come dicevamo, per default l’app mostra la galleria di foto e video, ma è solo una delle due modalità in cui può operare: l’altra è un file manager più tradizionale, esteticamente identico alla versione Web di OneDrive. Per passare dall’una all’altra visualizzazione c’è un tasto dedicato nella parte in alto a sinistra della pagina. Naturalmente è presente anche una barra di ricerca, ed è prevista l’integrazione dell'intelligenza artificiale di Copilot, in particolare grazie alla possibilità di richiamare una chat rapida con l’assistente semplicemente passando con il mouse sui vari file disponibili sul drive. Vale infine la pena segnalare che nella modalità galleria Microsoft mette a disposizione anche tutta una serie di strumenti per l’editing sia di foto sia di video, oltre a strumenti di organizzazione più avanzata come album e così via.

Il grande mistero rimane quale sia lo scopo di un’app del genere. OneDrive è già integrato direttamente a livello OS nelle varie versioni di Windows, la 11 inclusa - anzi, si potrebbe argomentare che è di quei software addirittura difficili da evitare, volenti o nolenti. In ogni caso, l’attesa per capire quali siano i piani di Microsoft a riguardo potrebbe essere molto breve: la società ha annunciato un evento speciale dedicato al servizio tra pochi giorni, l’8 ottobre.
