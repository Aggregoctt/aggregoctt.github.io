Dal prossimo mese, non sarà più possibile salvare nuove password all’interno dell’app Authenticator. A luglio, verranno disattivate le funzioni di riempimento automatico e cancellate le informazioni di pagamento. Infine, ad agosto, tutte le password memorizzate saranno eliminate definitivamente. L’app sta già notificando gli utenti, suggerendo come attivare l’autofill tramite Microsoft Edge, il browser della casa di Redmond.

Secondo Microsoft, questa decisione punta a uniformare la gestione delle credenziali all’interno del proprio ecosistema. Edge integra già strumenti come SmartScreen, Password Monitor e la ricerca InPrivate, rendendolo, secondo l’azienda, una soluzione più completa e sicura. Una mossa che segue quella di Google e Mozilla, che da tempo gestiscono le password direttamente tramite i propri browser.

Chi è già dentro l’ecosistema Microsoft può scegliere la transizione “guidata” verso Edge premendo il pulsante “Attiva Edge” nella notifica dell’app. In alternativa, è possibile esportare le proprie password in formato CSV direttamente dalle impostazioni di Authenticator, per poi importarle nel browser o password manager preferito.
