Tra i casi più rilevanti spiccano Visual Studio 2015, Windows 10 2015 LTSB e le edizioni IoT, Enterprise ed Education di Windows 11 versione 22H2, anch’esse destinate a terminare il supporto il 14 ottobre. Sul fronte cloud, Microsoft ritirerà servizi come Azure Database for MariaDB, Azure Basic Load Balancer e Azure Remote Rendering entro settembre, segnalando un ulteriore passo verso la razionalizzazione dell’offerta.

Per quanto riguarda la suite Office, il 14 ottobre sarà la data di addio per le versioni 2016 e 2019 di Word, Excel, PowerPoint, Outlook e Access, insieme a Skype for Business 2016 e 2019, Exchange Server 2016 e 2019, e Publisher. Anche Windows Server 2012 e 2012 R2 con Extended Security Updates vedranno la fine della copertura.
